# 🎵 Sistema de Streaming de Música

## 📋 Funcionalidades

- Cadastro de músicas
- Criação de playlists
- Reprodução de músicas
- Usuários Free e Premium
- Sistema de downloads
- Histórico de reprodução
- Recomendações

## 🏗️ Arquitetura

Projeto desenvolvido utilizando:
- Encapsulamento
- Herança
- Polimorfismo
- Interfaces
- Classes abstratas
- Pacotes Java

## 🚀 Como Executar

1. Abrir no VSCode
2. Compilar projeto Java
3. Executar StreamingMusica.java
